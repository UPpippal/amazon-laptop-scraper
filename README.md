# Amazon Laptop Scraper

## Objective

Scrape laptop data from Amazon.in and store it in a timestamped CSV file.

## Extracted Fields

* Product Title
* Image URL
* Rating
* Price
* Ad / Organic Result

## Technologies Used

* Python
* BeautifulSoup
* Pandas
* Google Colab

## Output

The scraped data is stored in a CSV file with a timestamped filename.

Example:
amazon_laptops_20260604_141813.csv
